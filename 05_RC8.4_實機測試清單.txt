MU Safety Assistant V1.50 RC8.4 試作版－實機測試清單

一、安裝與版本
[ ] 安裝後右側顯示 V1.50 RC8.4 試作版。
[ ] 工作統計中心與獨立報表輸出中心均存在。

二、文書流程
[ ] 選 4，顯示「辦公室／文書作業」，並詢問「今天主要做什麼文書作業？」。
[ ] 輸入文書名稱後完成填表，Google Form 工作內容只出現「辦公室／文書作業」。
[ ] 再選 4，文書問題預帶上次輸入值，可直接確定或修改。
[ ] 選 5，顯示「工務所／文書作業」，同樣預帶上次文書名稱。
[ ] 選其他範本，不出現文書問題。
[ ] 完成後自動捲至 Google Form 最底部，但不自動提交。

三、Records
[ ] 不同日期使用同一文書名稱，各自保存 documentWork。
[ ] 修改後的新文書名稱不會改動舊日期 Record。
[ ] 原有 muSafety.v150.rc7Records 歷史紀錄仍可查詢。

四、Excel
[ ] 月報與季報仍為真正 .xlsx，含「統計摘要」「工作明細」。
[ ] 工作明細含「文書作業內容」，舊 Record 顯示空白。
[ ] 統計摘要含「重要文書／專案成果」。
[ ] 同名文書跨 3 個不同日期時顯示「3 個工作日」。
[ ] 無紀錄月份只提示「此期間沒有工作紀錄」，不下載空白檔。

五、既有功能
[ ] 工作統計中心、搜尋／篩選、案號備註、缺失、夜間加班、一般填表均正常。
[ ] 專案代碼只填純案號，不含「｜備註」。
